# Bank Verification & IFSC Lookup Explanation

Currently, the application uses a **Hardcoded Prefix Matching** strategy to identify the bank name from the IFSC code. 

### How it works:
When the vendor enters an IFSC code, a listener in `bank_details_screen.dart` monitors the input. Once the input reaches 4 characters, the `getBankName()` function is called.

### The Logic (from the code):
The first 4 characters of an IFSC code represent the bank's unique identifier. The app checks these characters against a predefined list:

- **HDFC** -> HDFC Bank
- **SBIN** -> State Bank of India
- **ICIC** -> ICICI Bank
- **AXIS** -> Axis Bank
- **YESB** -> Yes Bank
- **KKBK** -> Kotak Mahindra Bank
- **PUNB** -> Punjab National Bank
- **BARB** -> Bank of Baroda

### Current Implementation State:
- **API Usage**: Currently, there is **NO external API call** for the Bank Name lookup itself. It is performed locally for speed and to avoid unnecessary network requests for common banks.
- **Verification**: While the name lookup is local, the actual **Account Verification** (checking if the account belongs to the vendor) happens via your backend API call to `/vendors/verify-bank`.

### Suggestion for Production:
For a more robust system that supports ALL banks (including smaller cooperatives), we can integrate a public API like:
- `https://ifsc.razorpay.com/[IFSC_CODE]`
- Or use a specialized Fintech API (Cashfree/Razorpay) if high accuracy is required for every branch.
