### Get Vendor Profile API Details

**Endpoint**: `GET /vendors/profile-full`
**Method**: `GET`
**Content-Type**: `application/json`
**Authorization**: Bearer Token required in headers

---

### Request Information
This is a standard GET request, so it does not require a request body. It fetches the complete vendor profile, including business statistics (like total jobs, total earnings, ratings, etc.) along with the basic profile details.

**Headers required:**
- `Authorization: Bearer <your_jwt_token>`

---
