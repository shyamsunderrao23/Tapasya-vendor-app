## Field Descriptions

| Field | Type | Description |
| :--- | :--- | :--- |
| `success` | Boolean | Indicates if the request was successful. |
| `message` | String | A human-readable message from the server. |
| `data.jwt_token` | String | The authentication token to be used for subsequent requests. |
| `data.vendor.id` | String (UUID) | Unique identifier for the vendor. |
| `data.vendor.fullName` | String | Vendor's full name. |
| `data.vendor.aadharStatus` | String | Status of Aadhar verification (`pending`, `submitted`, `approved`, `rejected`). |
| `data.vendor.status` | String | overall account status (`active`, `pending`, `inactive`). |
| `data.vendor.services` | Array | List of services the vendor is registered for. |
| `data.vendor.availability` | Array | Weekly working hours configuration. |

## Error Responses

### 401 Unauthorized (Invalid Token)
```json
{
  "success": false,
  "message": "Unauthorized: Invalid or expired Firebase token"
}
```

### 403 Forbidden (Vendor Not Found / Profile Incomplete)
```json
{
  "success": false,
  "message": "Vendor profile not found. Please register.",
  "data": {
    "is_registered": false
  }
}
```
